# 📊 Data Analytics Portfolio

Welcome to my primary Data Analytics portfolio repository! This space showcases end-to-end data analytics projects—ranging from exploratory relational database queries and SQL data cleaning to interactive business dashboards in Tableau, Excel, and Power BI.

---

## 🛠️ Tools & Technologies Used

* **Database Management & SQL:** Microsoft SQL Server Management Studio (SSMS)
* **Data Visualization & Dashboards:** Power BI Desktop, Tableau Public, Microsoft Excel (Pivot Tables, Dynamic Slicers)
* **Data Analytics & Modeling:** Power Query, DAX, Star Schema Modeling
* **Version Control:** Git, GitHub
* **Up Next:** Python Data Analysis (`pandas`, `numpy`, `matplotlib`, `seaborn`)
